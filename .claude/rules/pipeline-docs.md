# Documentation-First Development

## Rule 6: Documentation-First Development

**All projects follow the modular documentation standard in `docs/`. When making code changes, update the corresponding doc files as part of the same change. Read the relevant `docs/` file before modifying an area of the codebase. New architectural decisions require an ADR in `docs/decisions/`. Refer to each project's CLAUDE.md for specific documentation maintenance rules.**

For complete documentation standards, see `.claude/skills/docs-pipeline/`
